# Portfolio Website

This is a portfolio website built with Next.js and Tailwind CSS. It showcases my skills, experience, and projects. The website is responsive and adapts to different screen sizes.

## Features

- Responsive design: The website adapts to different screen sizes.
- Tailwind CSS: The website uses Tailwind CSS for styling.
- Next.js: The website is built with Next.js for server-side rendering.
- TypeScript: The website is written in TypeScript for better type checking.
- Dark mode: The website supports dark mode for a better user experience.
